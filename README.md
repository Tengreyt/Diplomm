# Keyboard Trainer / Diplom

Черновой старт для ВКР:

- `frontend` - Nuxt 4 интерфейс клавиатурного тренажера
- `backend` - простой Node.js API на Express

## Запуск

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend по умолчанию ожидает backend на `http://localhost:4001/api`.
